Case study · Contrast Revival

A recovery suite that opens the door for itself.

How a booking system wired to a smart lock let a Belfast recovery suite move to a fully self-service model — longer hours and more capacity, without anyone needing to be on site.

Client
Contrast Revival, recovery suite
The work
Booking & smart lock integration
Built with
C# / .NET · Azure · Nuki API
Running cost
~£5 a month

The problem

Every session meant someone travelling to the premises just to unlock the door. Opening hours were capped by when staff could physically be there — and every extra hour of cover was an extra cost for a small, growing business.

The bookings were already coming in online. The door was the only thing standing between the business and a self-service model.

What I built

A small, reliable app that connects the booking system to the smart lock on the front door. It runs quietly in the cloud on Azure — no server to look after, and running costs of about £5 a month.

1
A customer books
The booking system fires a webhook the moment a slot is paid for.
2
A door code is created
The app generates a unique code on the smart lock, valid only around the appointment time.
3
The customer gets it
The code is emailed automatically ahead of their session, with everything they need to know.
4
They let themselves in
The code works for their window, then expires on its own. No keys, no handovers, no staff.

The result

Contrast Revival now runs as a fully self-service operation. Sessions can be offered well beyond staffed hours, capacity is no longer tied to someone's availability, and the whole system costs about the price of a coffee each month to run.
